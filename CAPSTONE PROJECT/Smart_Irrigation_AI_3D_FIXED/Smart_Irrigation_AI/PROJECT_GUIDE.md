# Project Guide

## 1. Install
`pip install -r requirements.txt`

## 2. Train
`python train_model.py`

## 3. Run
`streamlit run app.py`

## 4. Demo inputs
Try:
- Soil moisture: 25
- Temperature: 35
- Humidity: 40
- Crop stage: Flowering
- Recent rainfall: 2

Then click **Analyze Irrigation Requirement**.

## Capstone alignment
Problem 17 expects environmental inputs related to irrigation requirement and a lightweight Streamlit prototype using a foundational classifier.
