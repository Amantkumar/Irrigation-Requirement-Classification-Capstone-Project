## 📌 Project Overview

Irrigation Requirement Classification is a machine learning-based project designed to classify whether irrigation is required based on agricultural and environmental conditions.

The system uses factors such as **soil moisture, temperature, humidity, crop stage, and recent rainfall** to predict whether irrigation is required or not.

The project demonstrates an end-to-end machine learning workflow including data preprocessing, exploratory data analysis, feature engineering, model training, model evaluation, and a Streamlit-based prediction prototype.

---

## 🎯 Problem Statement

Farmers often make irrigation decisions based on fixed schedules or manual observation. This project explores the use of machine learning as a decision-support approach for identifying irrigation requirements from environmental and agricultural data.

The classification target is:

- `0` → Irrigation Not Required
- `1` → Irrigation Required

---

## 🧠 Machine Learning Models

The project focuses on foundational classification algorithms:

- Logistic Regression
- K-Nearest Neighbours (KNN)
- Decision Tree

Models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Confusion Matrix
